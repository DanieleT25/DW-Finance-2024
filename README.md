# DW-Finance-2024
"DW Finance 2024” is an educational project that models a star‑schema data warehouse for 2024 financial transactions and provides an interactive Streamlit dashboard.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/DanieleT25/DW-Finance-2024.git
    cd DW-Finance-2024
    ```

2. Create and activate a virtual environment:
    ```bash
    python3 -m venv venvDWFinance
    source venvDWFinance/bin/activate  # On Windows, use `venvDWFinance\Scripts\activate`
    ```

3. Install the dependencies:
    ```bash
    pip install -r requirements.txt
    ```

4. Run streamlit:
    ```bash
    python3 LandingPage.py
    streamlit run LandingPage.py 
    ```
You can see the results [here](https://dw-finance-2024.streamlit.app).
